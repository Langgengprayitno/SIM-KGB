> agar lebih efisien, transparan, dan mudah dikelola.

## ✨ Fitur Utama

- 📋 Manajemen data pegawai
- 📈 Pengajuan & persetujuan kenaikan gaji berkala
- 🔔 Notifikasi jadwal KGB otomatis
- 📄 Cetak laporan & dokumen resmi
- 👥 Multi-role: Admin, Operator, Pimpinan

## 🛠️ Teknologi

| Layer    | Teknologi                        |
|----------|----------------------------------|
| Backend  | PHP 8.x, Laravel 10, CodeIgniter |
| Frontend | Blade, Bootstrap 5, JS           |
| Database | MySQL                            |
| Tools    | Git, VS Code                     |

## ⚙️ Instalasi

```bash
git clone https://github.com/Langgengprayitno/sim-kgb.git
cd sim-kgb
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```
